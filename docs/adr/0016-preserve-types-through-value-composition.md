# Preserve types through value composition

Public constructors use const generics and readonly tuples so literal Agent IDs, Tool names, schemas, Codecs, Hook Points, and fragment order survive `Agent.combine` and `Agent.define` without user-written generic arguments, `as const`, or `satisfies`. Agent Fragments carry composition metadata only through an inaccessible compile-time channel, and named helpers such as `Agent.Tools`, `Tool.Input`, and `Tool.ResumeInput` expose inferred types without runtime `$Infer` members, global augmentation, or public `any`; callback positions use the defining schema or Codec as their inference source rather than widening it. Core-owned IDs are opaque branded strings, `commissary({ agents })` preserves the installed Agent union, and `app.agent(agent)` returns an Agent Client retaining that Agent's specific Signals, outcomes, and resumptions; unbound Runtime Operations plus explicit dynamic Tool types provide honest escape hatches. Compile-time contract tests will cover both successful inference and rejected misuse, while cross-fragment identity conflicts remain runtime installation errors to keep compiler performance and diagnostics predictable.

The inaccessible Fragment metadata channel also carries open Effect requirements introduced by `@commissary/effect/ai`. Agent composition unions those requirements, and `@commissary/effect` reflects the resulting environment in its Layer input type without adding Effect types to core's ordinary constructors or inference helpers.
