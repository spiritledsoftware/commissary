# Compose Machine policy through typed Hooks

The public Hook namespace exposes one point-named constructor such as `Hook.beforeModelRequest(handler)` for every closed Hook Point, giving contextual inference and autocomplete for that point's event and permitted patch; `Hook.on(point, handler)` remains the adapter-oriented generic form. Transformations flow in author order, blocks short-circuit, exclusive replacements conflict unless that point defines a combinator, and notification handlers return exactly `undefined` rather than `void` so TypeScript rejects accidental patches. Hooks may adapt preparation, Context, model, provider, Tool, compaction, Branch, retry, steering, abort, and settlement seams, but receive neither a continuation nor Runtime Client and cannot invoke Runtime Operations, mutate an Execution Plan, intercept atomic Thread Store appends or guarded finalization, or replace orchestration; the Execution Attempt Signal stream remains the sole general observation interface.
