# Expose closed Runtime Operations to Drivers

The default Machine remains fixed, while a Runtime Client exposes the deep phase operations `prepare`, `invokeModel`, `executeTool`, `resumeTool`, and `finalize` to host-controlled Drivers; opaque phase products preserve Transcript loading, Render, validation, compatibility, and persistence invariants while a Driver owns cross-phase ordering, retries, claims, suspension, and completion. `finalize` accepts completion, Tool Suspension, Failure, or abort, verifies the prepared head and Execution Plan, commits at most one terminal transition, appends any resulting Model Message idempotently, and stores the Run Result. The operation map is closed, individual internal stages remain private, finalization is not hookable, and Agent Fragments cannot add operations or replace the Machine decision loop.
