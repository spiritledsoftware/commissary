# Store Thread history as branching Messages

The Thread Store is a host dependency that persists a parent-linked tree of immutable Message Entries, each containing one canonical Model Message; operational Run, claim, suspension, and result records live outside that message tree. Each Branch has a stable opaque ID, mutable Thread-local name, and head Message Entry ID and may fork from any existing entry without copying ancestry; core allocates entry IDs, while the store checks the expected head, derives parent links from batch order, advances the head atomically, and uses a commit ID to make uncertain append retries idempotent. The required store interface covers Thread and Branch creation, one-Branch path reads, renaming, and atomic appends; full-tree navigation and pagination belong to an optional inspection adapter.
