# Keep Effect behind JavaScript contracts

Commissary will use Effect internally for execution, streaming, cancellation, schemas, and typed errors, but public extension contracts will use ordinary objects and functions, synchronous values or `PromiseLike` values, `AsyncIterable` streams, and standard `AbortSignal` cancellation rather than Effect types. Standard Schema and Codec values are the source of truth for generic inference so callback inputs and declared outputs are inferred once from values rather than repeated as type arguments; provider-facing schemas additionally implement Standard JSON Schema V1. Expected Failures are operation-specific discriminated data, while unexpected exceptions, rejected Promises, invariant violations, and adapter faults are named `Error`-based Defects with preserved causes; core will not force every callback through a generic `Result` wrapper.

Effect AI is the internal Model execution substrate: Commissary uses its language-model services, streams, interruption, scopes, and typed errors behind the canonical Model protocol. Official integrations expose pure-JavaScript constructors and opaque Agent Fragments rather than public `Effect`, `Layer`, `Stream`, `LanguageModel`, or `AiError` values.

The Effect AI bridge exhaustively translates recognized `AiError` reasons into canonical Model Responses, Model Failures, or Interruptions. An `UnknownError`, an impossible Tool-resolution error while resolution is disabled, or any other unclassified bridge condition becomes a Defect; core does not infer recoverability from unknown provider data.

Core remains physically dependent on Effect for its internal implementation while its public interface remains free of Effect types. Optional application-facing Effect interfaces and adapter-authoring utilities live in `@commissary/effect`; its `@commissary/effect/ai` subpath exposes the canonical Model bridge for authors who intentionally use Effect AI. Other optional Effect Layers and integrations belong under the same package rather than core subpath exports.

Effect AI Model contributions authored through `@commissary/effect/ai` may retain open Layer requirements. The `@commissary/effect` construction interface combines those requirements across installed Agents and exposes them as input requirements of its Commissary Layer; ordinary pure-JavaScript provider integrations instead close their Effect requirements internally before returning Model contributions.
