## Observed common behavior

The simplest common behavior is **name-based late binding**: persist or replay a provider call ID plus Tool name and arguments; when work continues, use the currently registered Tool with that name. Most systems do not persist the advertised schema or a Tool implementation revision, and none inspected offers a list of compatible Tool revisions. Systems without a durable pending-execution model—OpenCode, current pi `AgentHarness`, Hermes Agent, Vercel AI SDK, and MCP—do not solve schema drift across process recovery at all; their session/history or protocol continuation must not be mistaken for durable Tool execution (sources in their rows above).

Two stronger contracts stand out, in different dimensions:

1. **Flue** has the strongest implemented durable execution policy: never blindly repeat an unresolved ordinary side effect, but allow explicitly durable Tools to resume from named, recorded `step.do` boundaries ([`.repos/flue/apps/docs/src/content/docs/guide/durability.md:36-39`](../../.repos/flue/apps/docs/src/content/docs/guide/durability.md#L36-L39)). It still does not identify a Tool schema revision.
2. **TanStack AI** has the strongest explicit contract-drift check: suspended interrupt bindings carry schema hashes and resume fails them as stale when the current Tool is absent or its schema changed ([`.repos/tanstack-ai/packages/ai/src/interrupts.ts:92-105`](../../.repos/tanstack-ai/packages/ai/src/interrupts.ts#L92-L105), [`.repos/tanstack-ai/packages/ai/src/interrupt-resume.ts:369-430`](../../.repos/tanstack-ai/packages/ai/src/interrupt-resume.ts#L369-L430)). Its own source is explicit that this contract is ephemeral, not a framework-owned durable recovery model ([`.repos/tanstack-ai/packages/ai/src/index.ts:169-173`](../../.repos/tanstack-ai/packages/ai/src/index.ts#L169-L173)).

## Commissary decision

Commissary uses name-based late binding. It records the Provider ID and Tool name, resolves the current Tool during recovery, validates the recorded effective input against the current contract, and uses the current continuation Codec to decode suspended state. A missing Tool, missing Suspension, invalid input, or decode failure produces a Stale Agent Interruption. It does not store a Tool revision, schema hash, server version, or compatible-revision list. This matches the existing static Tool compatibility rule while keeping at-least-once effects under the established idempotency contract.
