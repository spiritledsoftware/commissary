## Common patterns (observed)

1. **Per-event transforms are the safe streaming seam.** Vercel and TanStack transform chunks before downstream accumulation, so the terminal projection naturally matches what consumers saw.
2. **Final callbacks are usually observers.** TanStack `onFinish`, Cloudflare `onChatResponse`, Flue `useResponseFinish`, and Effect telemetry cannot replace output. Hermes and pi-mono are the exceptions, with explicit late replacement.
3. **Late replacement needs reconciliation or accepts split truth.** Hermes emits/edits a terminal replacement; pi-mono makes the terminal message authoritative without an evident compensating delta; Cloudflare deliberately allows persistence-only sanitization.
4. **Quality gates tend to continue, not rewrite.** Flue appends a corrective signal for another turn; TanStack may stop/abort loop continuation. General retry of a model call lives in provider/model wrappers or framework retry policy rather than post-finish observers.
5. **Provider middleware is distinct from agent hooks.** Vercel has an explicit model middleware contract. Effect exposes a replaceable service and composable stream. OpenCode, Cloudflare, Flue, and pi-mono require provider/stream-function wrapping for arbitrary decoded-output control; their general lifecycle hooks are narrower.

## Commissary decision

Commissary uses an ordered Model Event transformation pipeline before observation, accumulation, and persistence. The transformed terminal Event becomes the candidate final result. Final-result Hooks can then replace, block, or retry that candidate. Core emits one complete authoritative terminal Event and saves that exact result. Clients can display earlier Events as a preview but must replace it with the terminal result. Core Model Hooks run once around the root Model invocation; Composite Models and provider adapters own their internal call policy. Core does not silently rewrite only storage after public emission.

## Unresolved uncertainty

- Absence claims are based on the public types and execution paths in the pinned snapshots; undocumented internal extension points may exist.
- OpenCode’s provider hook type is imported rather than defined beside `Hooks`; a provider plugin can implement behavior beyond the lifecycle interface, but coherence guarantees are provider-specific.
- pi-mono’s exact UI reconciliation policy varies by frontend. The core/session path proves late state replacement; it does not itself prove every client ignores or reconciles earlier deltas.
- Cloudflare’s newer `think` package advertises `onChunk` lifecycle hooks in its changelog, but this comparison targets the inspected `AIChatAgent`/`ai-chat` implementation; `think` is a distinct higher-level package.
