# Security Policy

## Supported versions

Security fixes apply only to the latest published version of each `@commissary/*` package. The project does not maintain security fixes for older `0.x` versions.

## Report a vulnerability

Do not open a public issue, discussion, or pull request for a suspected vulnerability.

Use one of these private channels:

1. [Report a vulnerability through GitHub](https://github.com/spiritledsoftware/commissary/security/advisories/new).
2. Email [security@spiritledsoftware.com](mailto:security@spiritledsoftware.com) if GitHub private reporting is not available.

Include:

- The affected package and version.
- A clear description of the problem and its impact.
- Steps or code that reproduce the problem.
- Any known workaround.
- Your preferred contact details.

Never include real credentials, private data, or harmful production payloads.

## Response

Spirit-Led Software LLC will confirm receipt within five business days. We will investigate, give status updates when useful, and coordinate disclosure with the reporter. We will not promise a repair date before we understand the problem and its impact.

Please keep the report private until a fix or mitigation is available and a disclosure date is agreed.
