Draft verdict

The three specializations can share authoring, composition, precedence, null handling, custom encoded values, generated asset shape, failure ownership, format identity, and adapter handoff. Physical names, types, identity rules, and live driver checks remain database-specific. No database-named runtime Store interface is required.
